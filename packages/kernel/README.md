# @nexgent/kernel

The Nexgent runtime kernel: the root Cordis `Context`, plugin and service conventions, and (from step 1) profile loading, `ctx.agents`, `ctx.tools`, the agent loop and system-prompt assembly.

Step 0 (this version) only proves the dependency choice: `createApp()` creates a Cordis context and the `Greeter` example plugin shows a schemastery-validated config registering a service. Owned by plan step 1 (`docs/research/pr4-review-and-plan-2026-10/README.md`, section 4.1).

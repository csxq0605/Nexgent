# Nexgent Agent Relay

Agent Relay 是 Nexgent 的标准品牌标记：两段向前传递的形体表示主 Agent 与其运行中的 SubAgent、工具和工作流；两个节点分别表示任务来源与已交付结果。

- Ink `#171D3B`
- Night `#080B1D`
- Relay blue `#4B63FF`
- Relay violet `#8D43FF`
- Destination cyan `#22D3EE`
- Pale node `#E3E7FF`

标记四周至少保留图标宽度 12.5% 的净空；界面中的最小尺寸为 16 px。深色底使用 app icon，透明或浅色底使用 mark。不要旋转、改变节点位置、替换为立方体、在标记内部加入文字，或使用未经定义的颜色和阴影。

生产资产由 `scripts/build_brand_assets.py` 从 SVG master 确定性生成。

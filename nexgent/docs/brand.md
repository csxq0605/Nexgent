# Nexgent 品牌与产品语言

**名称：** Nexgent

**标语：** Agents in motion.

**英文描述：** A production-grade model-agnostic Agent Harness.
**中文描述：** 生产级、模型无关的 Agent Harness

产品语言直接、可执行、透明。状态文案应说明 Agent 正在做什么；权限文案应说明将执行的具体动作；错误文案应提供可恢复的下一步。GUI、TUI 与 CLI 共用 Nexgent、Agent、SubAgent、Workflow、Goal、Tool、Session 等术语，不把前端实现名当作产品概念。

Agent Relay 图标的 SVG master 与用法说明位于 `assets/brand/`。所有发布用位图必须通过 `scripts/build_brand_assets.py` 生成。

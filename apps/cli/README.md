# @nexgent/cli

The `nexgent` command-line entry point: `nexgent run` (new task), `nexgent resume <session>` (continue one) and `nexgent app` (launch the desktop app).

Step 0 ships a launcher (`bin/nexgent.mjs`) that answers `--version` and tells the user the commands are not implemented yet. `run` / `resume` are owned by plan step 1, `app` and the `npx nexgent` packaging by step 2 (`docs/research/pr4-review-and-plan-2026-10/README.md`, sections 4.1 and 4.10).

# 默认交付流程的产品修复

这轮以审计对话“审计PR2后的改动与目标偏离”为依据，修补默认 Nexgent/Main 的
交付和恢复。没有新增 demo、执行协议或发布账本。

用户现在可在同一入口提交任务、保留上传资料、查看独立验收、继续未完成的验收，
并保存反馈后按原资料重做。独立拒绝触发一次任务内修正与重新验收；其成果进入
原任务的最终输出。执行、评价和修正共用原任务硬预算。具体行为见
[框架入口说明](../framework-runtime.md#普通任务怎样完成)。

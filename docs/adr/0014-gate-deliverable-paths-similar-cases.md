# ADR 0014：门控按回放运行自己的成果检查文件，同类题按内容词判定

- **状态**：已接受
- **日期**：2026-10-14
- **依据**：用户 2026-10-14 09:13 对“试点开跑前先修门控”回复“B”。脚本化试点演练中，文件整理类的两个改进作业都因 `guard-regressed` 被退回。记录见资料库 `docs/handoff/step6-measure.md`，原始数据在 `validation-raw/step-6-pilot-rehearsal-20261014/`。
- **替代**：
  - ADR 0013 第 1 条“同类题”的定义；
  - ADR 0013 第 3 条的规则 id `adr-0013`，改为 `adr-0014`，因此进入新纪元。
  - ADR 0005、0006、0007、0008、0013 的其余部分仍然有效。

## 背景

1. **原路径检查。**
   - 任务结束时，宿主给本任务交付的每个文件记一条 `file-exists`，JSON、CSV、XLSX 文件再加一条 `parses`，路径都是原来那次运行自己起的文件名。门控回放时按这些路径检查两臂。
   - 反馈要求改名或挪位置时（例如“文件名不要有空格”），照做的候选在反馈原题上找不到原文件。组件对之后的任务同样生效，守护集里也会改名，于是守护集“退步”，结论是 `guard-regressed`。
   - 这和题目无关：任何改变输出命名或位置的改进都会被这样判，而原路径并不是任务的要求。
2. **同类题太宽。**
   - ADR 0013 落地时（PR #152），“同类题”被定义为与反馈原题首条消息至少有一个词相同。the、的、请这类词任何两条消息都有，所以几乎所有选择集用例都算同类题，`no-similar-cases` 几乎不会出现。
   - 选择集无论相似度高低都会补满 `selectionCases` 个用例，所以“在选择集里”本身不能说明是同类题。

## 决策

1. **记录的成果路径跟随回放运行自己的成果。**
   - 回放运行结束后，门控读取副本里这次运行 `present` 的成果文件（每个成果的最新版本，按交付顺序）。
   - 某条 `file-exists` 或 `parses` 记录的路径在副本里不存在时，改用这次运行交付的、扩展名相同的下一个文件来检查。这个文件不能已经位于某个记录路径上，也不能已经替过别的记录路径（一个文件只替一个路径）。同一路径的 `file-exists` 和 `parses` 用同一个替代文件。
   - 替代文件照常检查：存在、能解析。通过时检查结果写 `detail: "delivered under another path"`。
   - 没有交付同类文件，或者交付后又删掉，检查照旧失败。运行没有交付任何成果时，判法与以前相同。
   - 两臂、选择集与守护集都按这条判，用户任务自己提出的候选也一样。
   - `test-command` 不变：它是项目自己的测试命令。
2. **同类题按内容词判定。**
   - 同类题是选择集中除反馈原题以外、首条消息与反馈原题首条消息的内容词 Jaccard 重合度 ≥ 0.25 的用例（`SIMILAR_CASE_MIN`）。
   - 内容词沿用选择集的分词：小写字母与数字串，中日韩文字一字一词。去掉两类：
     1. 功能词：冠词、介词、代词、助动词，中文与日文的助词和量词（固定列表 `FUNCTION_WORDS`）；
     2. 纯数字：月份、编号、金额等单个实例的取值。它们在同一任务的两个实例之间本来就不同，ADR 0013 第 2 条也不让它们进组件。
   - **阈值依据**：0.25 表示两条消息各自至少有约五分之二的内容词相同。等长消息时，shared / (2n − shared) ≥ 1/4 等价于 shared ≥ 0.4n。这个值按这个含义取定，没有按任何题目拟合。
   - 只改“哪些用例算同类题”。选择集怎么挑、选几题都不变。
3. **新纪元。** 评价器规则 id 改为 `adr-0014`，纪元 id 随之改变。ADR 0008 第 5 条照常适用：`adr-0013` 纪元的门控结论、父子比较与报告，不和新纪元的放在一起。

## 后果

- 照反馈改名、换目录的候选不再因原路径缺失被判退步。它交付的文件仍要通过存在与解析检查，内容好坏仍由反馈检查与测试命令判断。
- 一个运行改交了另一个同类文件（例如换了一个名字但内容不对），存在检查会通过。存在检查本来只证明交了这类文件，这一点没有变。
- 同类题变严后，历史里没有同类任务的项目会更常出现 `no-similar-cases`，候选要等用户批准，自动采用会变少。这符合 ADR 0013 的本意：只在一道题上验证过的规则不自动成为长期规则。
- 功能词表是固定的通用语言列表，不针对任何任务；其他语言的功能词不在表里，这些语言的同类判定会偏宽。
- 试点计划要按新纪元重新冻结。

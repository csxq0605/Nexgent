# 注册批次：源码演化与科学发现 demo 的独立确认

日期：2026-09-16。状态：六项研究和一次确认均已完成；本报告保留全部注册结果。

## 1. 研究问题与定位

**Nexgent 的目标是通用 RSI 框架。科学发现是验证该框架的一项 demo，不是框架的领域限制。** 本批实验使用冻结的动力系统发现实现，检验智能体能否改变可执行程序，并通过独立评估改善这一 demo 的表现。它没有检验跨领域通用性，也没有发现新的自然定律。

本批观察到一次通过选择规则的 `task.py` 改进，在独立确认中平均分增加 **0.012351**。两个 `full` 研究都只产生了任务源码改动，没有改变并执行新的改进器；因此本批**没有产生递归改进能力增强的实证**。这是一份已完成实验的结果和下一轮设计依据，不构成通用 RSI 目标已经完成的声明。

## 2. 预登记与冻结

六项研究在任何本批模型调用前全部登记。两条独立演化种子为 **11、22**，每条包含 `full`、`task_only`、`greedy` 三个实验臂。共同起点为 `agent-07bf1dac73f145b3240d`，共同公开先验来自 `study-b1b2c2500a5f4d54` 的开发及选择证据。该先验带有失败案例，因此这批不是无先验的首次研究；它在各臂之间保持一致。

| 项目 | 固定设置 |
| --- | --- |
| 每项研究 | 3 代；最多 24 次模型调用、120,000 completion token 预约额度 |
| 数值约束 | 最多 48 次研究评估；每次最多 20,000,000 数值工作单位 |

| 确认执行 | 6 项研究 × 3 复现种子 × 2 程序 = 36 次；每次 20M；0 次模型调用 |

`full` 允许修改任务与改进器相关源码，并可从研究档案中的分支继续探索；`task_only` 冻结非任务源码，但保留档案探索；`greedy` 仍允许修改全部源码，只强制从当前启用的程序继续探索，不使用未晋升的研究分支。因此 `greedy` 是父程序选择策略的对照，并非冻结改进器对照；本批恰好没有产生改进器改动。它们比较的是实际实现的权限与探索策略。若 `full` 未实际修改改进器，则无法从实验臂名称推断已经发生 RSI。

晋升条件在本批执行前固定：质量分支要求均分增益 ≥ 0.002 且最差任务退步不超过 0.12；效率分支要求均分增益 ≥ −0.002、最差退步不超过 0.05，且工作量比 ≤ 0.85。这是工程准入规则，不能替代统计证据。选择集被研究流程反复使用，因此选择分数不作为独立确认结果。

## 3. 科学 demo 的观察、模型与评分

任务向 `solve(problem, tools)` 提供带噪状态轨迹、时间步长和维度，不提供系统家族、真实方程、隐藏参数或隐藏预测轨迹。程序自由组合平滑、导数或积分形式估计、表达式库、稀疏回归和可见轨迹验证，输出表达式及系数描述的常微分方程。静态强起点比较线性、多项式及扩展函数库，以及导数回归和积分配点两种估计组合。

每个确认批次包含 8 个训练家族内任务和 4 个不同家族任务；独立评分使用两个未见初值及更长预测范围。候选方程必须实际积分，不能仅凭拟合残差或自述获分。每任务得分为 `1 / (1 + 10 × NRMSE)`，批次得分为任务均值。隐藏轨迹由更细步长的数值参考生成。

数值发散或不合法模型是算法失败，记零分；进程超时、中断或预算无法完成是资源缺失，禁止当作观察到的零分。本次 36 次确认均完成，没有资源缺失；432 个重复执行的任务预测中有 24 次算法失败，已保留为零分。这里的 432 包含跨臂、初始/选定程序的重复任务，不是 432 个独立科研样本。

这一设计借鉴 [SINDy](https://doi.org/10.1073/pnas.1517384113) 的候选函数与稀疏方程恢复，以及 [弱形式系统识别](https://arxiv.org/abs/2005.04339) 对噪声敏感性的处理动机；目前的积分配点组合并非完整 WSINDy 复现。完整科研流程和一手文献职责见 [研究协议](reboot-scientific-protocol.md)；[FunSearch](https://www.nature.com/articles/s41586-023-06924-6)、[AI Scientist v2](https://arxiv.org/abs/2504.08066) 提供程序搜索与可执行研究的路径参考，不代表本项目已经复现其科学发现。

## 5. 对照与统计解释

先在每条演化 seed 内平均三个确认批次，再配对比较实验臂。独立演化样本量是 **n = 2**，不是确认种子数 3，也不是任务数 36 或重复预测数 432。预登记百分位 bootstrap 使用 10,000 次重采样、随机种子 713。

| 确认对照 | seed 11 差值 | seed 22 差值 | 平均差值 | 描述性 95% bootstrap 区间 |
| --- | ---: | ---: | ---: | --- |
| full − task_only | −0.012351 | 0 | −0.006176 | [−0.012351, 0] |
| full − greedy | 0 | 0 | 0 | [0, 0] |

样本极少，区间仅作探索性描述，不能声称可靠覆盖率或显著性。`[0, 0]` 来自两臂最终使用相同程序，并不证明总体等效。单条演化研究不提供独立演化置信区间。

更关键的识别限制是：本批两个 `full` 研究都未改变 `meta.py`、`workflow.py` 或 `roles.json`。`inherited_improver_executed` 均为空，实际后代生产能力的独立元评估也未进行。本批观察到的是“开放更大修改权限后实际产生的结果”，不能据此比较两个已经演化成功的改进器，不能把任务改进改名为元能力改进。

| 观察 | 直接证据 | 可检验的后续方向 |

| 源码声明不等于源码变化 | task_only/22 第 3 代初稿与父程序相同；修复稿仍有不匹配的机制源码锚点 | 将可执行差异、语法/接口检查和科学效果分开记录；失败消耗保留 |

| 领域与框架耦合 | 本批冻结实现把科学工具、提示、评分直接放入核心路径 | 迁移成独立 benchmark 插件，并用第二领域验证核心无需科学假定 |

以上是结果之后形成的下一轮假设，不是对本次登记条件的修改。后续改变框架、提示或元评估流程时，必须采用新的版本登记和新的验证问题，不能覆盖本次运行、重新利用本次确认集选冠军或只保留成功分支。

# Stage A 同题内核小样合同

日期：2026-09-23。状态：**实验预先约定；两条路径尚未通过。** 对应 [仓库计划 A](../../REFACTOR_PLAN.md#a-内核边界与技术选型)。此小样只比较后端承载能力，不测模型自主开发插件、RSI 增益或正式 benchmark 质量。

## 一条相同的任务

在空的任务作用域中，给执行者目标：“计算 6 × 7 并交付 JSON `{"answer": 42}`”。通过该后端的模型接口取得下一步动作，在该任务作用域装入**同一份人工编写的** `multiply` 工具，模型接口选择并调用 `multiply(6, 7)`，最终交付含结果的 JSON。将工具从作用域卸载，再按原名尝试调用；必须失败。新建另一任务作用域也不能看见该工具。

模型接口可以先用固定响应替身，以便两条路径遇到完全相同的请求和动作；随后用同一真实模型配置做接通检查，并分别报告替身／真实结果。替身只证明后端接口，不能算模型自主能力。工具只做本地确定性计算，避免把外部网络和不可恢复副作用混入第一次比较。

## 必须保留的共同收据

- `backend` 与固定源码版本、任务／会话／Episode 身份、模型配置或替身身份；
- 工具接口版本、源码／处理器摘要、已解析依赖、作用域及装入／卸载时刻；
- 模型请求／响应或完整可重建的消息事件、实际工具名／参数／结果、最终交付；
- 任务外不可见、卸载后不可调用的失败记录；中断后恢复所依据的事件或 RPC 收据；
- Nexgent `Episode` 和 `BenchmarkAdapter` 可读取的投影方式，以及任何丢失的字段。

小样在独立临时项目目录运行，不能读取或写入现有用户 Episode。测试后审查目录与依赖的实际位置。已安装宿主插件、受限 Python skill、模型可写通用插件、OS 隔离分别命名，不互相冒充。

DeepSeek 路径需将作用域注册／卸载与模型可见工具 schema 的变化分开观察。Creator 的持久安装会修改 profile 并在宿主进程执行，不能用它代替本合同要求的任务内隔离试装；如必须运行第三方代码，先另设隔离环境。模型可见消息以持久事件为证据，live 流只能供界面显示。Nexgent Episode 需额外记录 handler 摘要，因为上游工具事件本身未必含插件版本。

## 结果判定

每条路径分别记录：能否启动，装入／卸载是否真实改变可调用能力，任务和另一任务的作用域边界，工具和模型收据，暂停／恢复，Windows 安装与依赖，接入 Nexgent 版本和独立评价所需的适配量。失败保留复现命令、错误和环境；不得把文档接口列举当作运行通过。

最终 ADR 需从可运行证据选择一个生产主路径；如两条都不足，明确先补什么及已观察阻断。阶段 B 不以此小样的手写 `multiply` 推断阶段 C 的模型自主开发能力。
